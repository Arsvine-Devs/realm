## Audience and language

人类文档使用简体中文。命令、路径、标识符、API 名称、环境变量和错误消息保持权威英文形式。`docs/ai/` 与 `.agents/skills/` 下的 AI 操作文档使用简洁的技术英语。

## Maintenance policy

每个重要事实只保留一个权威所有者。命令、路由、配置键、范围边界或运维流程发生变化时，更新对应的人类参考文档和 AI 目录。文档只收录当前约束、操作步骤和运行风险。
