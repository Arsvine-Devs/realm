## Audience and language

Human documentation is primarily Simplified Chinese. Commands, paths, identifiers, API names, environment variables, and error messages remain in their authoritative English form. AI-facing operational files under `docs/ai/` and `.agents/skills/` use concise technical English.

## Maintenance policy

Each important fact should have one canonical owner. Update the relevant human reference and the AI index when a command, route, configuration key, scope boundary, or operational workflow changes. Do not add a new document merely to preserve a completed migration or a temporary design note.
