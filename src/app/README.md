# App Router 边界

[`Repository map`](../../INDEX.md) · [`Human documentation catalog`](../../docs/INDEX.md) · [`AI rules`](./AGENTS.md)

`src/app/` 是页面、layout、metadata、i18n、SSG/ISR、not-found 和 Route Handler HTTP 适配的框架边界。领域状态和外部服务逻辑属于 `src/features/` 或 `src/shared/`。

详见 [`docs/human/ARCHITECTURE.md`](../../docs/human/ARCHITECTURE.md) 和 [`docs/human/ROUTING_AND_I18N.md`](../../docs/human/ROUTING_AND_I18N.md)。
