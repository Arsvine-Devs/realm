# App Router boundary

`src/app/` contains the framework adapter for pages, layouts, metadata, i18n, SSG/ISR, not-found handling, and Route Handler HTTP adaptation. Domain state and external-service logic belong under `src/features/` or `src/shared/`.

See [`docs/human/ARCHITECTURE.md`](../../docs/human/ARCHITECTURE.md) and [`docs/human/ROUTING_AND_I18N.md`](../../docs/human/ROUTING_AND_I18N.md).
