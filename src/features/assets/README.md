# Asset Catalog feature

[`Feature domains`](../README.md) · [`Repository map`](../../../INDEX.md)

The assets feature resolves versioned COS Catalog data into application-facing records and optional site-shell assets.

- Runtime code lives under `model/` and `server/`.
- Source manifests remain beside their owning feature data.
- Generated hashes, Catalog versions, and public manifests belong to the local asset workflow, not to runtime source.
- Read [`docs/human/ASSETS.md`](../../../docs/human/ASSETS.md) for human procedures and [`AGENTS.md`](./AGENTS.md) for AI constraints.
